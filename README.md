# BSA Project Visibility and Overlap Tracker

Internal dashboard for tracking large project ownership, detecting system and stakeholder overlaps across Business Systems Analysts, and visualizing team workload.

## Features
- Large Projects tracker with BSA owner, systems, priority, and timeline
- Smartsheet integration for live enhancement requests
- Overlap detection across systems, stakeholders, and BSAs
- Workload heatmap
- Settings panel for managing team members and config

## Tech stack
Python (Flask), vanilla JavaScript, HTML/CSS, Smartsheet API, deployed on Render
